# Fit Journey 🏋️‍♂️

A simple and user-friendly fitness and health website designed to help users understand their fitness needs and maintain a healthy lifestyle.

## 🌐 Live Demo

https://firjourney.netlify.app/

## ✨ Features

- 🧮 BMI Calculator
- 🔥 BMR Calculator
- ⚡ Daily Calorie Requirement
- 💪 Protein Requirement
- 💧 Water Requirement
- 🥗 Diet Recommendations
- 🏋️ Workout Recommendations
- 📊 Fitness Tracking
- 📱 Responsive Design
- 🎯 Goal-Based Fitness Guidance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify
